# 00 — 总览与冻结契约

> 本文件是迁移项目的唯一真理源。所有 Phase 的 types / props / callbacks 以本文件为准。子 Agent 不得擅自修改；发现缺口在自查报告「契约疑问」提出，由总架构师裁定后回写本文件并通知相关 Phase。

## 1. 项目目标

将 old-vue-reader/（Vue 2，102 源文件，11 Plan 全 done）的全部能力与 UI 1:1 复刻到「数据无状态、UI 状态内聚」的 React 19 + TS 架构，拆分为可独立发布的 packages/reader、packages/epub-adapter 与宿主示例 apps/h5-demo。

复刻原则：架构可重构（分层 / Props / 回调 / 插槽），产品表现不可改（视觉 / 手势 / 文案 / 动效 / 边界常量）。

## 2. 目标架构

packages/reader（可发布阅读器库，零 API/路由依赖）：
- src/types/ — 冻结契约（本文件 §4–§6 的 TS 实现）
- src/core/ — 纯函数引擎（零 React 依赖；DOM 类型通过接口注入，jsdom 可测）：pagination / chapter-buffer / selection / highlights(line+note) / reading-position / bookmark-match / chapter-nav / book-css / reader-viewport / tts
- src/store/ — UI 状态（zustand）：ui-store / reading-store（高频独立 slice：globalPageIndex/dragOffset/isRebalancing/layoutLocked）/ settings-store（localStorage）/ annotation-store（pending lines+notes）/ bookmark-store（pending bookmarks）/ tts-store（播放态+engineRef）
- src/hooks/ — DOM 绑定层
- src/components/ — Reader.tsx（根+Props/回调）/ content（阅读引擎）/ chrome（顶栏底栏工具栏）/ overlays（选中/图片/脚注/试读）/ popups（目录/笔记/TTS）/ settings（设置/字体）

packages/epub-adapter：adapter.ts / resource-resolver.ts / index.ts（epub.js → 统一契约）

apps/h5-demo（H5 集成示例 + API 宿主）：
- src/api/ — 自 old-vue-reader/api 迁移（TS）
- src/host/ — ReaderHost.tsx（API ↔ Reader 桥接）/ host-store.ts（章节/标注/用户外部数据）
- src/routes/ — 宿主业务路由（随感等）
- src/slots/ — 插槽注入示例（ThoughtsMenuItem 等）
- src/App.tsx

pnpm-workspace.yaml：packages/* 与 apps/*

## 3. 状态边界

阅读器内部（内聚）：选区 · 翻页动画 · globalPageIndex · dragOffset · 主题/字号 · 面板开关 · TTS 播放态 · pending 标注（乐观 UI）

## 4. 冻结数据契约（types/）

字段严格对齐 old-vue-reader/prd/接口案例.md 真实返回与 utils/pos-info.js 锚点格式。posInfo / domPos 编解码字节级沿用 Vue，不改格式。

### 章节

ChapterMeta（初始化全量注入，源自 /chapter 列表）：
- id: number — 稳定 ID（与锚点/标注关联）
- chapterName: string — 章名（顶栏/目录显示）
- wordCount: number
- tag: string — "免费" / 付费标签（目录显示）
- isOrder: boolean — 是否已订购
- anchorId: string — 书签锚点 id（bookmark 编码用）
- index: number — 在 chapterList 中的序号（reader 侧补）

ChapterContent（按需注入，源自 /nextchapter）：
- chapterId: number
- chapterName: string — 章名（章首/顶栏）
- html: string — 渲染用 HTML 片段
- hasNext: boolean — 章末「下一章」按钮显隐/置灰
- pageButton: string
- baseUrl?: string — EPUB 模式相对资源基准（H5 为空）

ChapterAccess（按章注入，源自 /checkread + /nextchapter code）：
- chapterId: number
- canRead: boolean
- needLogin: boolean — 10003
- needPurchase: boolean — 10004
- isLoggedIn: boolean

ChapterLoadState = 'idle' | 'loading' | 'ready' | 'error'（按章注入，reader 渲染骨架/错误用）

### 标注

锚点格式：posInfo = { "0=1=7=0#N": charCode, ... }，domPos = "0=1=7=0#N"
划线色值规则：underlineColor.length > 7 → 黄底；否则蓝线（沿用 line-highlight.js）

LineItem（源自 /read/line/*，按 webLineId 索引）：
- id: number | null — 服务端 id（pending 时为 null）
- webLineId: string — 客户端临时 id（generateReaderWebId）
- clientId?: string — 乐观 UI reconcile 用（= webLineId，宿主回写时带回一个周期）
- chapterId: number
- posInfo: Record<string, number> — "0=1=7=0#N" → charCode
- summary: string — 摘要文本
- underlineColor: string — rgba(255,157,0,0.3) 黄底 | #0080FF 蓝线
- time?: string — "3分钟前"（笔记中心显示）

NoteItem（源自 /read/note/*）：
- id: number | null
- webNoteId: string
- clientId?: string
- chapterId: number
- posInfo: Record<string, number>
- summary: string
- content: string — 批注正文
- time?: string

BookmarkItem（源自 /getbookmark，按 chapter 分组）：
- id: string — = generateBookmarkId(chapterId, strIdx) 编码
- chapterId: number
- domPos: string — "0=1=0=0#0"
- summary: string — JSON 串或纯文本（encodeBookmarkSummary）
- precent: number — 注意：后端字段拼写为 precent，沿用
- cur: number — 当前页
- totalPage: number
- h5PageY: number — 竖滚模式页 Y
- strIdx: number — parseStrIdxFromBookmarkId
- pageIndex?: number
- time?: string — "3分钟前"（笔记中心显示，与 LineItem/NoteItem 一致）

### 阅读进度

ReadingSnapshot：
- chapterId: number
- domPos: string
- precent: number
- pageIndex?: number
- globalPageIndex?: number

### 书与用户

BookMeta：
- bookId: number
- bookName: string
- author: string
- bookPic: string — 封面
- paidChapterStart?: number — 付费章起点
- allowTts?: boolean — 是否允许 TTS（Vue bookMeta.allowTts !== false 才显示语音朗读入口；默认 true）

ReaderUser：
- isLoggedIn: boolean
- inBookshelf: boolean

TtsVoiceType（宿主注入，reader 不内置音色列表）：
- key: string — "BV102_streaming"
- label: string

TtsAudioEntry（按 reqId 索引，对应 onTtsAudioRequest）：
- reqId: string
- url: string
- text: string
- voiceType: string

## 6. 冻结回调契约（阅读器 → 宿主）

| 回调 | 触发时机 | payload |
|---|---|---|
| onChapterChange | 翻页至章边界 | (chapterId, width) — width 为容器测量值（Vue 默认 398） |
| onPrefetch | 章节切换后 | (chapterIds[], width) — 相邻章预取 |
| onLineCreate/Update/Delete | 划线乐观 UI 同步发出 | payload 含 clientId(=webLineId) |
| onNoteCreate/Delete | 批注乐观 UI 同步发出 | payload 含 clientId(=webNoteId) |
| onBookmarkCreate/Delete | 书签乐观 UI 同步发出 | payload |
| onAnnotationError | 乐观 UI 回滚时（可选） | { clientId, type, error } |
| onReadingPositionChange | debounce 800ms + 30s 定时 | ReadingSnapshot |
| onLinkClick | 正文链接点击 | href |
| onBookDetailClick | 目录弹窗书封点击 | bookId |
| onBookshelfAdd | 加入书架点击 | bookId |
| onLoginRequired | 付费/试读拦截 | 'paid' | 'trial_end' | 'auth' |
| onTtsAudioRequest | TTS 需音频（fire-and-forget） | { reqId, text, voiceType, chapterId } |
| onTtsReadTimeReport | TTS 播放时长上报 | { bookId, chapterId, seconds } |
| onReady | 阅读器初始化完成（宿主可注入 initialPosition） | — |
| onError | 章节/资源加载失败 | { scope, message } |

TTS 音频流（重要）：onTtsAudioRequest 是 fire-and-forget，不返回 Promise。宿主收到后调 fetchTtsAudio，拿到 URL 后通过 ttsAudioUrl prop（按 reqId）注入。reader 内部维护 reqId → url 队列，URL 到位即播。此范式与划线乐观 UI 一致，符合「数据无状态」原则。

## 7. 乐观 UI reconcile 协议

用户操作
  → ① DOM 高亮/包裹（wrapLineMark / syncChapterNotes）
  → ② 写入 reader 内部 pending（clientId = webLineId/webNoteId）
  → ③ 同步调用 onLineCreate / onNoteCreate / onBookmarkCreate（fire-and-forget，payload 带 clientId）
  → ④ 宿主调 API；成功 → 回写 lines/notes/bookmarks prop，对应项带原 clientId（一个周期后清除）
  → reader 收到 props：用 clientId 匹配 pending，替换为服务端 id，清除 pending
  → 失败 → 宿主注入 annotationFailure（nonce 递增）→ reader unwrap DOM + 移除 pending + Toast + 可选 onAnnotationError；宿主不回写 props

reconcile 关键：LineItem.clientId / NoteItem.clientId 是匹配键。宿主保存 clientId → serverId 映射，回写 prop 时把对应项的 clientId 带回（仅一个渲染周期），reader 据此 reconcile。BookmarkItem 用 id（编码自 chapterId+strIdx）直接匹配，无需 clientId。

## 8. 业务插槽边界

| 范围 | 归属 |
|---|---|
| 阅读引擎、划线、批注、书签、TTS、目录、设置 | packages/reader |
| 随感（列表/发布/点赞） | 仅 apps/h5-demo，通过 chromeSlots.topBarMoreMenu 注入入口 |
| 随感路由 /book/:id/thoughts | apps/h5-demo/routes/，reader 包零引用 |

reader 的 ReaderProps.chromeSlots 类型只暴露泛化 topBarMoreMenu(ctx)，不内置任何随感类型。随感是「示例用法」而非「内置能力」。
